# 0.2.1

## Configurable model token budgets

- Add required `maxContextWindowTokens` (32,769–2,000,000, default 220,000) and
  `maxOutputTokens` (2,048–32,768, default 32,000) installation settings, following
  the Producer pattern. Output must stay below the context window.
- The shared model helper now budgets responses from these settings instead of the
  previous fixed 3,000-token cap. Existing output-shape guards (bounded routing
  replies, extraction parsers, 16,000-character response limit) are unchanged.
- No breaking configuration changes; existing installations keep working and pick
  up the new defaults.
