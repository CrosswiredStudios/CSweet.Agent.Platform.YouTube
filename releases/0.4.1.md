- Pin the typed YouTube connector dependency to the publicly verified NuGet package `[0.2.1]`,
  avoiding approximate resolution of the unpublished 0.2.0 package.
- Require connector 0.2.1 or newer within the existing `<0.3.0` compatibility range and
  synchronize the agent, package, manifest configuration schema and version checks.
- Keep SDK 5.5.0, protocol 2.4 and existing channel authority/approval behavior unchanged.
  This dependency update does not establish real-Google acceptance or deploy the managed service.
