# 0.4.0

- Consume connector 0.2.0 and SDK 5.5.0 through NuGet packages; require protocol 2.4.
- Setup guidance now asks for an explicitly shared business channel instead of implying connecting
  Google alone authorizes the agent. Account connection, business grants and agent binding are separate.
- Preserve existing conversational reads, drafts, replies, uploads, edits and reporting workflows.

This is a development release. Fake-provider tests do not establish real-Google acceptance. Retention,
restricted feature coverage and operator verification requirements remain explicitly incomplete.
