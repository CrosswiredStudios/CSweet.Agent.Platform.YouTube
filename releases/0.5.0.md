# 0.5.0

Recurring comment monitoring and performance reports now require an explicit native
installation opt-in. The default completes channel onboarding without creating scheduled
duties, allowing on-demand channel help and conversational uploads with their existing
separate consent, grants and exact approval requirements.

An opt-in after onboarding creates missing duties on the next verified conversation
request after rechecking the saved channel. Disabling the setting blocks existing duties
without provider reads, model calls, deliveries or rescheduling, while retaining saved
progress. Re-enabling an already blocked duty requires native task resumption.

Existing installations with no explicit setting also default off. This update adds no
provider scopes, grants, direct network access or automatic posting. Synthetic tests do
not establish real-Google upload acceptance or provider-data erasure.
